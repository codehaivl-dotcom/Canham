# BURROW ZERO — Alliance / Coalition System v0.1

**Status:** Post-vertical-slice direction baseline

---

# 1. Principle

Alliance should add cooperation without making solo play invalid.

PvE and personal Silo remain complete without alliance.

---

# 2. Unlock

Prototype:
- CCL11 for full Coalition features;
- earlier lightweight social access possible at CCL7–8.

---

# 3. Alliance Size

Prototype:

```
20 members
```

Enough for social activity, small enough to keep identity.

Can test 20–30 later.

---

# 4. Roles

- Leader;
- Officer;
- Member.

No complex hierarchy initially.

Permissions:

Leader:
- settings;
- officer;
- projects;
- diplomacy.

Officer:
- invite;
- manage project contribution;
- event scheduling.

Member:
- contribute;
- participate.

---

# 5. Core Features

### Shared Chat
Basic.

### Intel Sharing
Members can share discovered temporary nodes / world boss intel.

### Trade Requests
Limited common material requests.

### Coalition Projects
Long-term shared construction.

### Alliance PvE
Cooperative boss/event contribution.

### Alliance Territory
Post-launch/endgame only.

---

# 6. Coalition Projects

Examples:

- Long-Range Relay;
- Regional Radar;
- Field Hospital;
- Trade Depot;
- Alien Observatory.

Contribution:

- capped daily/weekly;
- common + strategic resources;
- no whale infinite dump.

Rewards:
- alliance utility;
- cosmetics;
- event access.

---

# 7. Shared Radar

Alliance project can:

- reveal world event sooner;
- increase temporary target intel;
- show world boss.

Does not expose private player Silo exact layout.

---

# 8. Trade

Member requests:

- Food;
- Water;
- Scrap;
- common Components;
- Chemicals.

Not tradable:

- unique blueprint;
- survivor;
- Artifact;
- boss key progression.

Daily limits prevent alt abuse.

---

# 9. Alliance PvE

Boss contribution can be asynchronous:

- each member runs personal encounter;
- damage/progress adds to alliance objective;
- shared milestone rewards.

Avoid requiring 20 players online simultaneously.

---

# 10. Alliance PvP

Later system:

- seasonal regional objective;
- resource control;
- Silo raid support intel.

Do not launch with large 4X war.

No alliance can erase another alliance's bases.

---

# 11. Alliance Membership Protection

Members cannot normal-raid each other.

Leaving alliance:
- 24h cooldown before joining another during competitive season.

Kick:
- contribution rewards already earned not removed.

---

# 12. Alliance Rewards

Focus:

- cosmetics;
- banner;
- alliance room decoration;
- shared cache;
- alternate progression;
- convenience.

No alliance-exclusive mandatory best weapon.

---

# 13. Solo Compatibility

Solo player must still access:

- all core PvE;
- most blueprints;
- endgame story;
- bosses;
- PvP.

Alliance improves:
- efficiency;
- social play;
- event scale;
- prestige.

---

# 14. Success Criteria

Alliance works if:

- useful without mandatory attendance;
- asynchronous participation works;
- no 4X-style dominance;
- social identity exists;
- solo remains viable.
