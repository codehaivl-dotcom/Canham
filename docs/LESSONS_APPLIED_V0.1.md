# 1. Escape from Duckov

Official Steam nhấn mạnh:

- ever-changing loot/enemies/weather;
- extract or lose field loot;
- bring valuables back;
- build base;
- craft;
- blueprints;
- quests/story.

PC Gamer ghi nhận:

- junk dùng cho base facilities/crafting/vendor/quest;
- quest tạo directed progression;
- single protected item safety valve.

## Học

### A. Greed curve — LOCK

Càng đi sâu càng có reward tốt nhưng attrition tăng.

### B. Multi-axis progression — LOCK

Run có thể tiến gear + Silo + XP + Bestiary + contract + blueprint.

### C. Quest as onboarding — LOCK

Silo Need / Story Signal dẫn tới location phù hợp.

### D. Fixed identity + variable run — LOCK

Hospital vẫn là Hospital nhưng threat/route/loot biến đổi.

### E. Bad-luck protection — LOCK

Boss/progression luôn có guaranteed fragment/data.

### F. Source clarity — LOCK

Item nói nhóm nguồn likely.

### G. Protected data slot — EXPERIMENT

Secure Data Case bảo vệ 1 blueprint/data item; chưa khóa.

## Không học

- shooter control;
- loot Tetris;
- excessive grind;
- wiki-dependent source discovery.

# 2. Fallout Shelter

Bethesda nhấn mạnh:

- room readability;
- Dwellers có job;
- happiness;
- training;
- Wasteland exploration.

## Học

### A. Cutaway readability — LOCK

Nhìn Silo phải hiểu ngay room đang làm gì.

### B. People visible in rooms — LOCK

Survivor không biến thành spreadsheet.

### C. Simple interaction — LOCK

Combat không micro RTS.

### D. Base life matters — LOCK

Job/Morale/Training nối survivor với Silo.

## Không copy

- SPECIAL;
- Vault structure/art;
- exact room gameplay;
- Fallout IP expression.

# 4. Bunker Buster

Steam mô tả:

- power;
- air;
- water;
- food;
- sanitation;
- morale;
- research;
- unique faction technology;
- fortress raiding/PvP.

## Học

### A. Infrastructure must be legible — LOCK

Power/life-support là gameplay, không décor.

### B. Captured tech should change options — LOCK

Boss/faction technology mở recipe/system mới, không chỉ +5%.

### C. Base defense uses same infrastructure — LOCK

Power/doors/security có ý nghĩa khi bị raid.

## Không học

- fortress weapon-systems là nhân vật chính;
- quá nhiều infrastructure simulation trước khi core loop vui.

# 5. System Arrival

Steam mô tả:

- venture out for supplies;
- return to underground bunker;
- turn supplies into equipment/base improvements;
- survivor needs/jobs;
- DNA study unlock recipes/abilities.

## Học

### A. Every loot item should answer “what can this improve?” — LOCK

Loot ↔ base link rõ.

### B. Enemy knowledge can unlock progression — LOCK

Bestiary/Sample → Research.

### C. Deep expedition should make return harder — LOCK

Attrition/route/extraction pressure tăng theo depth.

## Không học

- action-RPG combat;
- psychic-power identity.

# 6. Signature Combination We Must Protect

Không game reference nào được kéo design xa khỏi:

```
NAMED SURVIVORS
+
READABLE ROOM COMBAT
+
IMPERFECT INTEL
+
LOADOUT SOFT-COUNTERS
+
GREED / EXTRACTION
+
SILO LIFE SUPPORT
+
CLEAR-TO-EXPAND BASE
+
BASE-AS-PVP-DUNGEON
+
CONTESTED RESOURCE WORLD
```

Đây là identity của BURROW ZERO.
