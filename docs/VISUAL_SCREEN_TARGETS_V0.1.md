# BURROW ZERO — 10 Core Visual Screen Targets v0.1

**Status:** LOCKED visual target list  
**Dependency:** ART_PRODUCTION_V0.1.md

These are layout/gameplay targets, not pixel-perfect final UI.

---

# 1. Main Silo / Home

Must show:

- cutaway Silo;
- 3+ room levels;
- panda survivors working;
- Power/Water/Food/Scrap;
- Build / Staff / Upgrade;
- World/Deploy shortcut.

Visual goal:
"This is my home."

---

# 2. Dig & Expand Silo

Must show:

- controlled room;
- rock/unknown adjacent sector;
- engineer;
- excavation preview;
- state labels such as Unknown/Unsafe/Controlled;
- Excavate / Seal / Restore/Convert when relevant.

Visual goal:
"Base expansion is exploration."

---

# 3. Survivor Roster & Loadout

Must show:

- selected panda 3D preview;
- role/profession/trait;
- weapon/armor/utility/consumable;
- roster list/filter;
- no human rarity stars.

Visual goal:
"These are my survivors."

---

# 4. World Map / Radio Scan

Must show:

- central Silo;
- House/Hospital/Warehouse/Military/Unknown nodes;
- distance;
- fog/unknown signals;
- Resource Site/faction markers later;
- current contract.

Visual goal:
"There is a world beyond the bunker."

---

# 5. Mission Preparation

Must show:

- target card;
- Intel confidence;
- threat/likely loot;
- squad 3–5;
- consumables;
- Supply cost;
- Deploy.

Visual goal:
"Preparation is gameplay."

---

# 6. Dungeon Exploration

Must show:

- room with 2 route choices;
- panda squad;
- loot/interactable;
- partial map/unknown route;
- cargo;
- Extract accessible.

Visual goal:
"I don't know everything ahead."

---

# 7. Combat Room

Must show:

- readable formation;
- enemy silhouettes;
- HP portraits;
- target focus;
- consumable;
- simple VFX;
- limited UI.

Visual goal:
"Easy to read, hard to prepare."

---

# 8. Boss Encounter

Must show:

- one large simple boss;
- clear weak point/state;
- 4–5 panda squad;
- mechanic telegraph;
- minimal arena props.

Visual goal:
"The boss is a mechanic, not an HP wall."

---

# 9. Extraction / Return / Cache Reveal

Must show sequence or screen family:

- injured survivors;
- recovered loot;
- cache opening;
- 5-card reward reveal;
- Blueprint/Bestiary progress.

Visual goal:
"The risk paid off."

---

# 10. Player Silo PvP Raid

Must show:

- cutaway enemy Silo;
- revealed rooms + ???;
- attacker route;
- Alarm;
- Security/Power/Vault/Command;
- Extract option.

Visual goal:
"Another player's home becomes my dungeon."

---

# 11. Shared Visual Rules

Every screen:

- simple low-poly geometry;
- panda shared body;
- dark charcoal + warm yellow core palette;
- large shapes;
- real localized UI text;
- no tiny decorative clutter;
- readable on 16:9 desktop first;
- adaptable to touch later.

---

# 12. Production Priority

Prototype visual order:

1. Main Silo;
2. Dungeon Exploration;
3. Combat;
4. Mission Preparation;
5. World Map;
6. Roster;
7. Expansion;
8. Cache/Return;
9. Boss;
10. PvP Raid.

The first three define the visual identity of the actual game.
